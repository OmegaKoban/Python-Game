## 1. Игровые механики

### 1.1 Основная петля (Core Loop)

```
[Спавн волны врагов] → [Игрок двигается и уклоняется] → [Оружие автоатакует ближайших врагов] → [Враг умирает → дроп опыта/золота] → [Level Up: выбор усиления] → [Волна усиливается] → [Повтор / Смерть игрока]
```

1. **Спавн волны врагов** — враги появляются за пределами видимой области экрана (вокруг камеры) с заданным интервалом на бесконечной арене; интервал сокращается, а состав волны усложняется по игровому таймеру.
2. **Действие игрока** — игрок перемещается (WASD/стрелки), выбирая позицию так, чтобы избежать урона и держать врагов в радиусе действия оружия.
3. **Реакция мира** — установленное оружие атакует автоматически: находит цель (ближайшего врага) и наносит урон без участия игрока.
4. **Результат** — убитые враги оставляют кристаллы опыта и монеты; игрок подбирает их движением по арене.
5. **Повтор / Level Up** — при наборе достаточного опыта игра ставится на паузу, игрок выбирает 1 из 2–3 усилений, после чего волна продолжается и постепенно нарастает по сложности.

### 1.2 Управление

| Кнопка / Ввод | Действие |
|---------------|----------|
| `←` `→` / `A` `D` | Движение влево/вправо |
| `↑` `↓` / `W` `S` | Движение вверх/вниз |
| ЛКМ / клавиши не требуются для атаки | Атака выполняется автоматически системой оружия |
| `1` / `2` / `3` (или клик мышью) | Выбор усиления на экране Level Up |
| `Esc` / `P` | Пауза |

### 1.3 Механика движения

- **Скорость игрока:** 200 px/с (базовая), может увеличиваться пассивными усилениями (+10–20%)
- **Гравитация:** отсутствует — top-down вид, движение по 8 направлениям
- **Прыжок:** отсутствует
- **Ограничения:** арена бесконечная — жёстких границ нет, игрок может двигаться во всех направлениях без ограничений; камера следует за игроком, мир генерируется/повторяется динамически вокруг неё; столкновение с врагами не блокирует движение, но наносит урон при контакте

### 1.4 Боевая механика / Основное взаимодействие

- **Нанесение урона:** оружие игрока автоматически выбирает ближайшего врага в радиусе действия и атакует с заданной частотой (attack rate); урон = базовый урон оружия × модификаторы усилений
- **Получение урона:** контакт с врагом или вражеским снарядом снижает HP игрока; после получения урона краткая неуязвимость (i-frames) ~0.5 с
- **Условие победы (забег):** продержаться заданное время на бесконечной арене (например, 10 минут) — засчитывается как "победа" в забеге, либо цель по очкам
- **Условие поражения:** HP игрока опускается до 0 → экран Game Over с итоговым счётом

### 1.5 Прогрессия и нарастание сложности

| Этап | Условие | Изменение |
|------|---------|-----------|
| Старт | 0:00 | Базовые враги (1 тип), базовое оружие, HP игрока 100 |
| Волна 2 | 1:30 | +20% скорость спавна врагов, появляется 2-й тип врага |
| Волна 3 | 3:00 | +30% HP врагов, появляется 3-й тип (быстрый/стрелок) |
| Волна 4 | 5:00 | +40% плотность спавна, элитные враги с усиленным HP |
| Финал | 8:00–10:00 | Максимальная плотность волн, потенциальный "финальный" враг/босс (пост-MVP) |

## 2. Игровые сущности

### 2.1 Игрок

| Параметр | Значение |
|----------|----------|
| HP | 100 |
| Скорость | 200 px/с |
| Базовый урон (стартовое оружие) | 10 |
| Радиус подбора опыта/монет | 40 px |
| Спрайт | `player_idle.png`, `player_run.png`, 32×32 px |

### 2.2 Враги

| Тип | HP | Скорость | Урон | Поведение | Спрайт |
|-----|----|----------|------|-----------|--------|
| Магическая сфера 1 | 20 | 90 px/с | 8 | Прямое преследование игрока | `enemy_crawler.png` |
| Магическая сфера 2 | 15 | 160 px/с | 5 | Быстрое сближение по прямой, слабый урон | `enemy_runner.png` |
| Большая магическая сфера | 80 | 100 px/с | 15 | Как базовый, увеличенный HP/урон, появляется с 3-й волны | `enemy_elite.png` |

### 2.3 Оружие и усиления (выбираются на Level Up)

| Предмет | Эффект | Тип | Спрайт |
|---------|--------|-----|--------|
| Стартовый клинок | Автоатака ближайшего врага в ближнем радиусе | Активное оружие | `weapon_blade.png` |
| Автоарбалет | Автовыстрел снарядом в ближайшего врага, дальний радиус | Активное оружие | `weapon_crossbow.png` |
| Магический снаряд | Автовыстрел снарядом в ближайшего врага, дальний радиус | Активное оружие |`weapon_magic.png` |
| Огненный шар | Автовыстрел снарядом в ближайшего врага, средний радиусб урон по области | Активное оружие |`weapon_fireball.png` |
| Огненная аура | Периодический урон по area вокруг игрока | Активное оружие | `weapon_aura.png` |
| Ускорение | +15% скорость передвижения | Пассивное усиление | `boost_speed.png` |
| Больше HP | +20 максимального HP | Пассивное усиление | `boost_hp.png` |
| Ускорение атаки | +15% частота атаки всех орудий | Пассивное усиление | `boost_atkspeed.png` |

### 2.4 Дроп-предметы

| Предмет | Эффект | Длительность | Спрайт |
|---------|--------|--------------|--------|
| Кристалл опыта | +XP (величина зависит от типа врага) | Мгновенно | `xp_gem.png` |
| Монета | постоянные усиления(в главном меню) | Мгновенно | `coin.png` |
| Аптечка (редкий дроп) | +25 HP | Мгновенно | `heal.png` |

### 2.5 Уровни / Окружение

- **Количество уровней:** 1 бесконечная арена без границ (endless survival, без фиксированных уровней в MVP)
- **Тип генерации:** фон состоит из повторяющегося тайла (`background_tile.png`), который динамически дорисовывается вокруг камеры по мере движения игрока (без жёсткой карты и без процедурной генерации объектов в MVP)
- **Размер арены:** бесконечный мир без границ; камера с viewport `800×600` следует за игроком, враги спавнятся за пределами видимой области
- **Тайлсет:** `tileset_ground.png`, тайл 32×32 px

## 3. Интерфейс (UI / UX)

### 3.1 Схема экранов

```
[Главное меню]
      │
      ├─── [Настройки]
      │
      ├─── [Рекорды]
      │
      └─── [Игра] ──── [Пауза] ──── [Главное меню]
                │
                ├─── [Level Up] ──── [Игра] (продолжение)
                │
                └─── [Game Over] ──── [Главное меню]
                                 └─── [Играть снова]
```

### 3.2 Главное меню

*Вайрфрейм:*

```
┌──────────────────────────────┐
│          AUTO ARSENAL        │
│                              │
│        [ Играть     ]        │
│        [ Настройки  ]        │
│        [ Рекорды    ]        │
│        [ Выход      ]        │
│                              │                
└──────────────────────────────┘
```

### 3.3 HUD (Heads-Up Display)

*Вайрфрейм:*

```
┌────────────────────────────────────┐
│ Счёт: 340     ⏱ 02:34              │
│ XP ▓▓▓▓▓▓▓▓▓░░░░ Ур.4              │
│                                    │
│            [игровая сцена]         │
│                                    │
└────────────────────────────────────┘
```

| Элемент | Позиция | Описание |
|---------|---------|----------|
| Полоса HP | Снизу под игроком | Текущее HP игрока (числом и полосой) |
| Таймер выживания | Верх-лево | Время, прошедшее с начала забега |
| Полоса опыта / уровень | Верх экрана на всю длину | Прогресс до следующего Level Up |
| Счёт | Верх-лево (возле таймера) | Текущее количество набранных очков |

### 3.4 Экран выбора усиления (Level Up)

```
┌──────────────────────────────────────────────┐
│               ВЫБЕРИ УСИЛЕНИЕ                │
│                                              │
│ [ Усиление 1 ] [ Усиление 2 ] [ Усиление 3 ] │
│                                              │
└──────────────────────────────────────────────┘
```

### 3.5 Экран паузы

```
┌──────────────────────────────┐
│           ПАУЗА              │
│                              │
│      [ Продолжить   ]        │
│      [ Главное меню ]        │
└──────────────────────────────┘
```

### 3.6 Экран Game Over

```
┌──────────────────────────────┐
│          GAME OVER           │
│                              │
│      Ваш счёт: XXXX          │
│      Время выживания: MM:SS  │
│      Рекорд:   XXXX          │
│                              │
│      [ Играть снова ]        │
│      [ Главное меню ]        │
└──────────────────────────────┘
```
