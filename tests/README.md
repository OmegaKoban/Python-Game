# Тестирование Auto Arsenal

Этот каталог содержит автоматические тесты для игры Auto Arsenal.

## Запуск всех тестов

```bash
# Из корневой папки проекта:
python tests/run_tests.py

# Или из папки tests:
cd tests
python run_tests.py
```

## Запуск отдельных тестовых модулей

```bash
# Тесты коллизий
python -m unittest tests.test_collision

# Тесты игрока
python -m unittest tests.test_player

# Тесты врагов
python -m unittest tests.test_enemy
```

## Запуск конкретного теста

```bash
python -m unittest tests.test_collision.TestCollisionSystem.test_collision_zones_loaded
```

## Структура тестов

### test_collision.py
Тестирует систему коллизий:
- Загрузка зон коллизий
- Обнаружение коллизий
- Разрешение коллизий (откат и скольжение)
- Ограничение границами карты

### test_player.py
Тестирует настройки и механики игрока:
- Корректность параметров (скорость, HP, урон)
- Систему опыта и уровней
- Систему способностей
- Систему улучшений

### test_enemy.py
Тестирует систему врагов:
- Корректность параметров всех типов врагов
- Систему волн и спавна
- Прогрессию сложности
- Разблокировку новых типов врагов

## Добавление новых тестов

1. Создайте файл `test_<название>.py` в папке `tests/`
2. Импортируйте unittest и тестируемые модули
3. Создайте класс, наследующий `unittest.TestCase`
4. Напишите методы тестов (имя должно начинаться с `test_`)
5. Запустите тесты через `run_tests.py`

### Пример теста:

```python
import unittest
from src import settings

class TestMyFeature(unittest.TestCase):
    def test_something(self):
        self.assertEqual(1 + 1, 2, "Математика работает!")

if __name__ == '__main__':
    unittest.main()
```

## Требования

- Python 3.x
- Pygame
- unittest (входит в стандартную библиотеку Python)

## Советы

- Запускайте тесты после каждого изменения кода
- Пишите тесты для новых функций перед их реализацией (TDD)
- Стремитесь к 100% покрытию критической логики
- Используйте осмысленные имена тестов
- Добавляйте сообщения к `assert` для понятной диагностики
