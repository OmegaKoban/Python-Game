# Auto Arsenal

Roguelike-выживач (survivor / bullet-heaven) с автоатакой против нарастающих волн врагов.
Проект написан на **Python** с использованием фреймворка **pygame**.

## Концепция

Полное описание игровой концепции — в файле [Концепт-документ.md](./Концепт-документ.md).

Кратко: игрок перемещается по арене, оружие атакует врагов автоматически, задача — выживать против всё более плотных волн противников, набирать опыт, качаться и продержаться как можно дольше.

## UX/UI

Игра использует вид сверху (top-down) в пиксель-арт стилистике. Управление максимально
простое: игрок отвечает только за перемещение, а оружие атакует врагов автоматически —
всё внимание уходит на позиционирование и уклонение от волн.

### Главное меню

При запуске игрок попадает в главное меню с четырьмя пунктами: **Играть**, **Настройки**,
**Рекорды**, **Выход**.

![Главное меню Auto Arsenal](./docs/ui_main_menu.jpg)

### Игровой экран

Основной геймплей: персонаж в центре арены, вокруг набегают враги (гоблины, слизни и др.).
Оружие бьёт автоматически по ближайшему противнику — на скриншоте виден летящий снаряд.

![Игровой экран Auto Arsenal](./docs/ui_gameplay.jpg)

Элементы интерфейса (HUD):

| Элемент | Где | Что показывает |
|---|---|---|
| **Счёт** | слева сверху | набранные очки за убийства |
| **Таймер** ⏱ | слева сверху | сколько игрок продержался |
| **Полоска опыта + Ур.** | слева сверху | прогресс до следующего уровня и текущий уровень |
| **Полоска здоровья** | под персонажем | оставшееся HP игрока (зелёная убывает при уроне) |
| **Полоски HP врагов** | над врагами | здоровье противника (появляются при получении урона) |

### Управление

| Действие | Клавиши |
|---|---|
| Движение | **WASD** или **стрелки** |
| Атака | **автоматическая** — по ближайшему врагу в радиусе |
| Рестарт после поражения | **R** |
| Выход / пауза меню | **ESC** |

Никаких кнопок атаки — игрок только двигается и выбирает позицию, а всё остальное
(наведение, стрельба, выбор цели) происходит само. Это ключевая идея жанра survivor.
