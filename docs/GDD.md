## 1. Игровые механики

### 1.1 Основная петля (Core Loop)

```
[Спавн волны врагов] → [Игрок двигается и уклоняется] → [Оружие автоатакует ближайших врагов] → [Враг умирает → дроп опыта/лечения] → [Level Up: выбор усиления] → [Волна усиливается] → [Повтор / Смерть игрока]
```

1. **Спавн волны врагов** — враги появляются за пределами видимой области экрана (вокруг камеры) с заданным интервалом на бесконечной арене; интервал сокращается, а состав волны усложняется по игровому таймеру.
2. **Действие игрока** — игрок перемещается (WASD/стрелки), выбирая позицию так, чтобы избежать урона и держать врагов в радиусе действия оружия.
3. **Реакция мира** — установленное оружие атакует автоматически: находит цель (ближайшего врага) и наносит урон без участия игрока.
4. **Результат** — убитые враги оставляют кристаллы опыта и монеты; игрок подбирает их движением по арене.
5. **Повтор / Level Up** — при наборе достаточного опыта игра ставится на паузу, игрок выбирает 1 из 2–3 усилений, после чего волна продолжается и постепенно нарастает по сложности.

### 1.2 Управление

| Кнопка / Ввод | Действие |
|---------------|----------|
| `←` `→` / `A` `D` | Движение влево/вправо |
| `↑` `↓` / `W` `S` | Движение вверх/вниз |
| Атака | Выполняется автоматически по ближайшему врагу |
| `1` / `2` / `3` | Выбор усиления на экране Level Up (цифровые клавиши) |
| `←` `→` / `Enter` / `Space` | Навигация и выбор в меню Level Up |
| ЛКМ на карточку усиления | Выбор усиления мышью |
| `Esc` | Пауза / Возврат в главное меню |
| `R` | Рестарт после Game Over |
| `P` | Продолжить (из паузы) |
| `Q` | Выход в главное меню (из паузы) |

### 1.3 Механика движения

- **Скорость игрока:** 220 px/с (базовая), может увеличиваться пассивными усилениями
- **Гравитация:** отсутствует — top-down вид, движение по 8 направлениям
- **Прыжок:** отсутствует
- **Ограничения:** карта фиксированного размера 3000×3000 px (1 тайл), камера следует за игроком с зумом 0.9; враги спавнятся за границами экрана, игрок не может выйти за края карты

### 1.4 Боевая механика / Основное взаимодействие

- **Нанесение урона:** 
  - Игрок автоматически атакует ближайшего врага в радиусе 500 px с базовой частотой 0.9 сек
  - Базовый урон: 34 единицы (увеличивается пассивным усилением +10% за выбор)
  - Режим боя: дальний (ranged) — выпускает снаряды, которые летят к цели со скоростью 520 px/с
  - Снаряды живут 1.5 сек и имеют радиус попадания 14 px
- **Активные способности (разблокируются при Level Up):**
  - Огненная пуля — снаряд в ближайшего врага, урон 20, кулдаун 0.9 сек
  - Огненная аура — урон по кругу вокруг игрока, урон 8, радиус 120 px, кулдаун 0.5 сек
  - Атака молнией — мгновенный урон 30 ближайшему врагу в радиусе 500 px, кулдаун 1.4 сек
  - Фаербол — взрыв по области при попадании, урон 40, радиус взрыва 90 px, кулдаун 2.2 сек
  - Метеорит — падает в случайную точку карты, урон 60, радиус 130 px, кулдаун 3.0 сек
  - Каждая способность качается до 8 уровня (урон/радиус растёт, кулдаун падает)
- **Получение урона:** контакт с врагом наносит урон (зависит от типа врага: 8–24 единиц); после урона неуязвимость 0.6 сек
- **Условие победы:** продержаться максимальное время, набрать максимальный счёт (количество убитых врагов)
- **Условие поражения:** HP игрока опускается до 0 → экран Game Over с итоговым счётом и временем выживания

### 1.5 Прогрессия и нарастание сложности

**Система опыта:**
- Формула порога уровня: `XP_BASE * (XP_GROWTH^(N-1)) + XP_FLAT_ADD*(N-1)`
- Базовые параметры: XP_BASE=5, XP_GROWTH=1.35, XP_FLAT_ADD=3
- Опыт за врагов: slime1=1, slime2=2, slime3=4, orc1=2, orc2=4, orc3=7 XP

**Волны врагов:**

| Волна | Условие | Количество врагов | Изменения |
|-------|---------|-------------------|-----------|
| 1 | Старт (+2 сек) | 5 | Только slime1 и orc1 (базовые типы) |
| 2 | +6 сек после волны 1 | 8 | +60% врагов, продолжают появляться slime1/orc1 |
| 3 | +6 сек после волны 2 | 11 | +60% врагов, продолжают появляться slime1/orc1 |
| 4 | +6 сек после волны 3 | 14 | Разблокируются slime2 и orc2 (средний тир) |
| 5+ | Каждые 6 сек | +3 врага за волну | Рост плотности |
| 8 | +6 сек после волны 7 | 26 | Разблокируются slime3 и orc3 (сильный тир) |

**Рост характеристик врагов:**
- HP: +6% за каждую волну после первой
- Урон: +4% за каждую волну после первой
- Интервал спавна внутри волны: 0.35 сек между врагами

**Система взвешивания типов:**
- Вес типа при разблокировке: 10.0
- Рост веса: +3.0 за каждую волну после разблокировки
- Минимальный вес старых типов: 4.0 (чтобы не исчезали полностью)

## 2. Игровые сущности

### 2.1 Игрок

| Параметр | Значение |
|----------|----------|
| HP | 100 (базовое) |
| Скорость | 220 px/с |
| Базовый урон автоатаки | 34 |
| Интервал автоатаки | 0.9 сек (минимум 0.15 сек при прокачке) |
| Радиус атаки | 500 px |
| Радиус подбора опыта (магнит) | 160 px |
| Радиус сбора опыта | 34 px |
| Размер спрайта | 187×187 px (TILE_SIZE * 0.25/4.0) |
| Хитбокс | 40% ширины × 60% высоты спрайта |
| Неуязвимость после урона | 0.6 сек |
| Анимации | idle (8 кадров), run (6 кадров), attack1 (4 кадра), attack2 (4 кадра) |
| Спрайты | `Warrior_Idle.png`, `Warrior_Run.png`, `Warrior_Attack1.png`, `Warrior_Attack2.png` |

### 2.2 Враги

**Типы врагов (6 тиров):**

| Тип | HP | Скорость | Урон | Размер | Разблокировка | Опыт | Анимации |
|-----|----|----------|------|--------|---------------|------|----------|
| slime1 | 30 | 110 px/с | 8 | 0.9×192px | Волна 1 | 1 XP | run (8), attack (10), hurt (5), death (10) |
| slime2 | 60 | 120 px/с | 12 | 1.0×192px | Волна 4 | 2 XP | run (8), attack (11), hurt (5), death (10) |
| slime3 | 100 | 130 px/с | 16 | 1.15×192px | Волна 8 | 4 XP | run (8), attack (9), hurt (5), death (10) |
| orc1 | 60 | 85 px/с | 14 | 1.0×192px | Волна 1 | 2 XP | run (8), attack (8), hurt (6), death (8) |
| orc2 | 100 | 90 px/с | 18 | 1.1×192px | Волна 4 | 4 XP | run (8), attack (8), hurt (6), death (8) |
| orc3 | 150 | 95 px/с | 24 | 1.25×192px | Волна 8 | 7 XP | run (8), attack (8), hurt (6), death (8) |

**Поведение:**
- Все враги преследуют игрока по прямой линии
- При контакте с игроком запускается анимация атаки
- Урон наносится в середине анимации атаки (один раз)
- Кулдаун атаки: 0.8 сек (повторный урон при продолжительном контакте)
- Хитбоксы: slimes 50%×50%, orcs 45%×60% от размера спрайта
- При получении урона проигрывается короткая анимация hurt (не прерывает смерть)
- При смерти проигрывается анимация death (макс. 1.5 сек), затем враг исчезает

**Дропы при смерти:**
- Кристалл опыта (XP) — всегда
- Аптечка (heal) — 8% шанс, восстанавливает 25 HP

**Папки со спрайтами:**
```
assets/enemy/slime1/{run,attack,hurt,death}.png
assets/enemy/slime2/{run,attack,hurt,death}.png
assets/enemy/slime3/{run,attack,hurt,death}.png
assets/enemy/orc1/{run,attack,hurt,death}.png
assets/enemy/orc2/{run,attack,hurt,death}.png
assets/enemy/orc3/{run,attack,hurt,death}.png
```

### 2.3 Система улучшений (Level Up)

**Механика выбора:**
- При повышении уровня игра ставится на паузу
- Игрок выбирает 1 из 3 случайных улучшений
- Выбор: цифры 1/2/3, стрелки + Enter, или клик мышью по карточке

**Пассивные усиления (можно выбирать многократно):**

| ID | Название | Эффект |
|----|----------|--------|
| dmg | Сила атаки +10% | Множитель урона всех атак × 1.10 |
| aspd | Скорость атаки +7% | Интервал атаки × 0.93 (минимум 0.15 сек) |
| hp | Здоровье +20 | +20 к максимуму HP и текущему HP |

**Активные способности (прокачиваются до 8 уровня):**

| ID | Название | Тип | Параметры уровня 1 | Рост при прокачке |
|----|----------|-----|-------------------|-------------------|
| fireball | Огненная пуля | projectile | 20 урон, 0.9 кулдаун | +8 урон, кулдаун ×0.92 |
| aura | Огненная аура | aura | 8 урон, 120 радиус, 0.5 кулдаун | +4 урон, +16 радиус, кулдаун ×0.95 |
| lightning | Атака молнией | lightning | 30 урон, 500 радиус, 1.4 кулдаун | +12 урон, +40 радиус, кулдаун ×0.9 |
| fireball_aoe | Фаербол | fireball_aoe | 40 урон, 90 взрыв, 2.2 кулдаун | +16 урон, +12 радиус, кулдаун ×0.9 |
| meteor | Метеорит | meteor | 60 урон, 130 радиус, 3.0 кулдаун | +24 урон, +16 радиус, кулдаун ×0.9 |

**Визуальные эффекты способностей:**
- Снаряды и взрывы рисуются процедурно (круги, линии)
- Пути к спрайтам указаны в `settings.ABILITIES`, но пока не используются в коде
- Молния: зигзаг из линий сверху вниз к цели
- Метеорит: падающий камень + тень-маркер на земле

### 2.4 Дроп-предметы (Pickups)

**Механика подбора (магнит):**
- Дропы лежат на месте (слегка покачиваются)
- При приближении игрока на 160 px — притягиваются к нему
- Подбираются автоматически на расстоянии 34 px
- Скорость притягивания: 420 px/с (ускоряется со временем)
- Время жизни несобранного дропа: 25 секунд

**Типы дропов:**

| Предмет | Эффект | Размер | Визуал | Спрайт |
|---------|--------|--------|--------|--------|
| Кристалл опыта (XP) | +XP (зависит от типа врага) | 22×22 px | Голубой ромб (заглушка) | Не используется |
| Аптечка (heal) | +25 HP | 50×50 px | Зелёный крест / спрайт | `assets/effects/heal.png` |

**Источники дропов:**
- XP — выпадает всегда при смерти врага
- Аптечка — 8% шанс при смерти врага

### 2.5 Уровни / Окружение

- **Количество уровней:** 1 фиксированная арена 3000×3000 px (1 большой тайл)
- **Тип генерации:** фон — одна текстура тайла (`tile.jpeg`), растянутая на всю карту
- **Размер арены:** 3000×3000 px (настраивается через MAP_WIDTH_TILES × MAP_HEIGHT_TILES × TILE_SIZE)
- **Камера:** 
  - Viewport зависит от разрешения экрана (зум 0.9)
  - Следует за игроком, ограничена границами карты
  - Враги спавнятся за пределами видимой области камеры
- **Тайлсет:** `assets/tiles/tile.jpeg` или `tile1.png`

## 3. Интерфейс (UI / UX)

### 3.1 Схема экранов

```
[Главное меню]
      │
      ├─── [Настройки]
      │
      ├─── [Рекорды]
      │
      └─── [Игра] ──── [Пауза] ──── [Главное меню]
                │
                ├─── [Level Up] ──── [Игра] (продолжение)
                │
                └─── [Game Over] ──── [Главное меню]
                                 └─── [Играть снова]
```

### 3.2 Главное меню

*Реализация:*

```
┌──────────────────────────────┐
│    [Фон-небо с облаками]     │
│                              │
│     [Панель-пергамент]       │
│        AUTO ARSENAL          │
│                              │
│        [ Играть     ]        │
│        [ Настройки  ]        │
│        [ Рекорды    ]        │
│        [ Выход      ]        │
│                              │                
└──────────────────────────────┘
```

**Особенности:**
- Фон: `background.png` (небо) с анимированными облаками
- 6 типов облаков (`cloud_1.png` — `cloud_6.png`) движутся слева направо
- Скорость облаков: 14–46 px/с (случайная)
- Панель-пергамент: `panel.png`, масштабируется под 48% ширины экрана
- Навигация: мышь (hover + click) или клавиши ↑↓ + Enter
- ESC в меню = выход из игры

### 3.3 HUD (Heads-Up Display)

*Реализация:*

```
┌────────────────────────────────────┐
│ HP ▓▓▓▓▓▓▓░░░ 70/100              │
│ XP ▓▓▓▓▓▓▓▓▓░░░░ Ур.4   Волна: 3  │
│                       Счёт: 28     │
│            [игровая сцена]         │
│                                    │
└────────────────────────────────────┘
```

| Элемент | Позиция | Описание |
|---------|---------|----------|
| Полоса HP | Верх-лево | Текущее/максимальное HP игрока (числом и полосой) |
| Полоса XP | Под полосой HP | Прогресс до следующего уровня + номер текущего уровня |
| Номер волны | Верх-право | Текущий номер волны врагов |
| Счёт | Под номером волны | Количество убитых врагов |
| Полоски HP врагов | Над каждым врагом | Красная полоса (скрыта при полном HP) |

**Параметры:**
- Шрифт HUD: размер 22 px
- Шрифт HP: размер 20 px
- Цвет текста: (235, 235, 245)
- Цвет полосы HP игрока: фон (60, 20, 25), заполнение (70, 210, 120)
- Цвет полосы XP: фон (30, 30, 50), заполнение (120, 200, 255)
- Цвет полосы HP врага: фон (50, 20, 20), заполнение (220, 70, 70)

### 3.4 Экран выбора усиления (Level Up)

```
┌──────────────────────────────────────────────┐
│            ПОВЫШЕНИЕ УРОВНЯ                  │
```

**Управление:**
- Цифры 1/2/3 — быстрый выбор

- ЛКМ на карточку — выбор мышью

**Визуал:**
- Игра ставится на паузу
- Затемнённый фон (полупрозрачный оверлей)
- 3 карточки усилений с названием и описанием
- Подсвеченная рамка вокруг выбранной карточки
- При наведении мыши — изменение цвета

```
┌──────────────────────────────┐
│          GAME OVER           │
│                              │
│      Убито врагов: XX        │
│      Волна: X                │
│                              │
│      [ Играть снова (R) ]    │
│      [ Главное меню     ]    │
└──────────────────────────────┘
```

**Особенности:**
- Результаты автоматически сохраняются в `records.json`
- Формат рекорда: имя игрока, количество убийств, волна, дата
- R — быстрый рестарт
- ЛКМ / Enter — выбор пункта меню

## 5. Техническая реализация

### 5.1 Архитектура

**Структура проекта:**
```
Python-Game/
├── main.py                 # Точка входа, игровой цикл, управление состояниями
├── src/
│   ├── settings.py         # Все настройки и константы игры
│   ├── entity.py           # Базовый класс для анимированных сущностей
│   ├── player.py           # Персонаж игрока
│   ├── enemy.py            # Враги с типами и анимациями
│   ├── projectile.py       # Снаряды игрока
│   ├── abilities.py        # Система активных способностей
│   ├── pickups.py          # Дропы (XP, heal) с магнитом
│   ├── wave_manager.py     # Управление волнами врагов
│   ├── camera.py           # Камера с зумом
│   ├── tilemap.py          # Карта арены
│   ├── hud.py              # UI поверх игры
│   ├── menu.py             # Главное меню и подменю
│   └── records.py          # Сохранение/загрузка рекордов
├── assets/                 # Все графические и звуковые ассеты
└── docs/                   # Документация проекта
```

**Состояния приложения:**
- `STATE_MENU` — главное меню
- `STATE_SETTINGS` — экран настроек (имя игрока, яркость, громкость)
- `STATE_RECORDS` — таблица рекордов
- `STATE_PLAYING` — игровой процесс
- `STATE_PAUSED` — пауза

### 5.2 Ключевые системы

**Система анимации (AnimatedEntity):**
- Базовый класс для игрока и врагов
- Загрузка спрайт-листов (горизонтальные ряды кадров)
- Автоматическое переключение кадров по таймеру
- Поддержка отражения по горизонтали (facing_right)
- Отдельные хитбоксы для коллизий

**Система волн (WaveManager):**
- Таймер до следующей волны (WAVE_INTERVAL = 6 сек)
- Расчёт состава волны по типам врагов (unlock wave + веса)
- Спавн врагов за границами камеры с интервалом 0.35 сек
- Масштабирование HP/урона врагов от номера волны

**Система способностей (AbilityManager):**
- Независимые кулдауны для каждой способности
- Визуальные эффекты с временем жизни
- 5 типов: projectile, aura, lightning, fireball_aoe, meteor
- Прокачка уровня увеличивает урон/радиус, уменьшает кулдаун

**Система дропов (Pickup):**
- Покадровая анимация покачивания
- Магнит: притягивание на расстоянии 160 px
- Автосбор на расстоянии 34 px
- Время жизни: 25 секунд

### 5.3 Настройки экрана

**Режимы отображения (SCREEN_MODE):**
- `"fullscreen"` — полноэкранный (рекомендуется для macOS)
- `"borderless"` — без рамки на весь экран (на macOS не скрывает menu bar)
- `"window"` — оконный режим

**Особенности:**
- Используется pygame.SCALED для автомасштабирования под разрешение
- Зум камеры: 0.9 (CAMERA_ZOOM)
- VSync включён при поддержке драйвером
- FPS: 60 (настраивается через settings.FPS)

### 5.4 Отладка

**DEBUG_HITBOXES:**
- При `True` рисует красные рамки вокруг хитбоксов игрока и врагов
- Помогает настроить PLAYER_HITBOX_SCALE и ENEMY_HITBOX_SCALE под спрайты
- Выключить перед релизом

### 5.5 Сохранение данных

**records.json:**
- Формат: список словарей `{player, kills, wave, date}`
- Автосохранение при Game Over
- Отображение в меню "Рекорды"
- Сортировка по количеству убийств
