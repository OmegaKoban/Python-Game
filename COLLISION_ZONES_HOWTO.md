# 🛡️ Как добавить зоны коллизий (домики и препятствия)

## Шаг 1: Найди координаты домиков

### Запусти утилиту:
```bash
python find_collision_zones.py
```

### Используй мышь:
1. **ЛКМ** — кликни на **левый верхний угол** домика
2. **ЛКМ** — кликни на **правый нижний угол** домика
3. **ENTER** — сохранить прямоугольник
4. **R** — сбросить текущие точки (если ошибся)
5. Повтори для всех домиков
6. **ESC** — выход и сохранение

### Результат:
Файл `collision_zones.txt` с координатами:
```python
COLLISION_ZONES = [
    # Дом 1
    (450, 320, 680, 520),
    # Дом 2
    (1200, 800, 1450, 1050),
]
```

---

## Шаг 2: Добавь координаты в settings.py

Открой `src/settings.py` и найди секцию `COLLISION_ZONES`:

```python
# Зоны коллизий (домики, препятствия)
COLLISION_ZONES = [
    # Скопируй сюда из collision_zones.txt
    (450, 320, 680, 520),  # Дом 1
    (1200, 800, 1450, 1050),  # Дом 2
    # ...
]
```

---

## Шаг 3: Проверь в игре

1. **Запусти игру:**
   ```bash
   python main.py
   ```

2. **Зоны будут видны синими рамками** (если `DEBUG_COLLISION_ZONES = True`)

3. **Попробуй пройти через домик** — персонаж должен упираться в невидимую стену

---

## Шаг 4: Отключи отладочную визуализацию

Когда всё настроишь, отключи синие рамки в `src/settings.py`:

```python
DEBUG_COLLISION_ZONES = False
```

---

## 🎮 Как это работает

1. **TileMap** загружает зоны коллизий из `settings.COLLISION_ZONES`
2. **Player.update()** сохраняет предыдущую позицию перед движением
3. **TileMap.resolve_collision()** проверяет столкновение с домиками
4. Если есть коллизия — откатывает игрока к предыдущей позиции

## 🔧 Дополнительно

### Альтернативный способ — вручную в графическом редакторе:

1. Открой `assets/tiles/tile.jpeg` в GIMP/Photoshop
2. Включи отображение координат курсора
3. Наведи на углы домика и запиши координаты
4. Формат: `(левый_верхний_x, левый_верхний_y, правый_нижний_x, правый_нижний_y)`

### Враги тоже упираются в домики?

Нет, пока коллизии только для игрока. Чтобы враги тоже упирались:

1. Открой `src/enemy.py`
2. В методе `update()` найди движение к игроку
3. Добавь такую же проверку коллизий, как в Player

## ❓ FAQ

**Q: Зоны не отображаются?**  
A: Проверь `DEBUG_COLLISION_ZONES = True` в settings.py

**Q: Игрок проходит сквозь домики?**  
A: Проверь, что координаты правильные и список не пустой

**Q: Координаты не те?**  
A: Перезапусти утилиту и кликай точнее по углам

**Q: Можно ли делать круглые зоны?**  
A: Да, но нужно переписать `check_collision()` на расчёт расстояния
